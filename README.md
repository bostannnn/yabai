# yabai

yabai is an experimental Android reader app for self-hosted book and comic servers or local files reading.

I've built it in a spare time as a hobby, because I couldn't find a reader that i've liked. 
It was made for my tablet and I didn't test it on a phone. 

## Supported formats

- EPUB
- PDF
- CBZ
- CBR

## Main features

- Connect to Kavita and Grimmory libraries
- Basic Stump integration
- Read books, PDFs, manga, and comics
- Download items for offline reading
- Track reading progress locally
- Pull and push reading progress with supported servers
- Build a reading history journal from progress activity
- Browse libraries with reading status and format-aware views

## Status

yabai is early, experimental software. Features, server support, and sync behavior are still evolving.
